Update the following values:


SystemSerialNumber = Serial

MLB = Board Serial

SystemUUID = SmUUID

AppleRom = Your Ethernet adapter MAC address (called "Physical Address" in Windows).

Example MAC Address: 00:1A:2B:3C:4D:5E

ROM value: 001A2B3C4D5E

Replace the existing serial numbers with the values generated by GenSMBIOS, then save the config.plist file. After that, you are ready to install macOS Tahoe.
